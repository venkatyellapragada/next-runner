# Speaker photos

Drop one portrait per person here, named exactly as below, then redeploy.
JPG, PNG or WebP all work. Use about 800 px on the long side and under 300 KB: the audience page loads them on venue wifi.
The image is cropped to fill (portrait 4:5 on the speaker slide, square elsewhere), anchored a little above centre so faces stay in frame.
Until a file exists the person shows as initials. /control → Content check lists what is still missing.
A person with `"photo": false` in content/event.json (Manasa Krishna) is shown with no picture at all and needs no file.
